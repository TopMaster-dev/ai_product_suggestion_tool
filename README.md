# Logo（ロゴ）— フェーズ① 社内チャットボット

## フォルダ構成

```
phase1/
├── backend/
│   ├── main.py            # FastAPI バックエンド（全コメント日本語）
│   ├── schema.sql         # MySQLテーブル定義・サンプルデータ（日本語列名）
│   ├── requirements.txt   # Pythonパッケージ一覧
│   └── .env.example       # 環境変数テンプレート
└── frontend/
    ├── app/
    │   ├── layout.tsx     # Next.js レイアウト
    │   ├── page.tsx       # メインページ
    │   └── globals.css    # グローバルCSS（CSS変数も日本語）
    └── components/
        ├── サイドバー.tsx      # 左固定サイドバー
        ├── メイン画面.tsx      # ダッシュボード
        └── チャットパネル.tsx  # AIチャットパネル
```

---

## 処理フロー

```
① ユーザーが日本語で入力
       ↓
② 自然言語解析・意図抽出（Claude AI）
   → カテゴリ / 用途 / 条件リスト / キーワードリスト 等に分解
       ↓
③ データベース検索（MySQL「商品マスター」）
   → 抽出条件でSQLを動的生成
   → 在庫あり・廃番なしの商品のみ取得
   → 販売ランク順・在庫数順で並び替え
       ↓
④ AI推薦文生成（Claude AI）
   → 商品データのみをもとに日本語で説明・推薦理由を生成
   → 不明な点は「データにございません」と回答
       ↓
⑤ 画面に表示
   → チャット回答文 + 処理ステップ + 商品カード（画像・価格・在庫）
```

## セットアップ手順

### 1. MySQL の準備

```bash
# schema.sql を実行してデータベースと商品テーブルを作成
mysql -u root -p < backend/schema.sql
```

### 2. バックエンド（Python）の起動

```bash
cd backend

# 環境変数ファイルを作成
cp .env.example .env
# .env を開いてAPIキーとDB情報を入力

# 仮想環境を作成・有効化
python -m venv venv
source venv/bin/activate        # Windows の場合: venv\Scripts\activate

# 必要パッケージをインストール
pip install -r requirements.txt

# サーバー起動
uvicorn main:app --reload --port 8000
```

起動確認：http://127.0.0.1:8000/api/ヘルスチェック

### 3. フロントエンド（Next.js）の起動

```bash
cd frontend

# パッケージインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 を開く

## 画面の使い方

```
┌──────────┬──────────────────────────────┐
│          │                              │
│ サイドバー│      ダッシュボード           │
│（固定）  │                              │
│          │  「チャットを開く」ボタン     │
│          │                              │
└──────────┴──────────────────────────────┘
            ↓ ボタンクリック後
┌──────────┬───────────────┬──────────────┐
│          │               │              │
│ サイドバー│ ダッシュボード │ チャットパネル│
│（固定）  │   （左半分）   │   （右半分）  │
│          │               │              │
└──────────┴───────────────┴──────────────┘
```

1. 「チャットを開く」をクリックすると画面が左右に分割される
2. 右側のチャットパネルに日本語で商品条件を入力する
3. AIが3ステップで分析・検索・推薦文を生成する
4. 回答・処理ログ・商品カードが表示される

## データベース列名一覧（日本語）

| 列名           | 内容                           |
|--------------|-------------------------------|
| 商品ID         | 自動採番の主キー               |
| 商品コード     | 社内管理コード（ユニーク）      |
| JANコード      | バーコード用コード             |
| 商品名         | 商品の正式名称                 |
| メーカー名     | 製造メーカー                   |
| カテゴリ       | 大分類                         |
| サブカテゴリ   | 小分類                         |
| 卸価格_税抜    | 得意先への卸売価格（税抜）      |
| 参考売価_税抜  | 消費者向け参考価格（税抜）      |
| 定価_税抜      | メーカー希望小売価格（税抜）    |
| 入数           | 1ケースあたりの入り数           |
| 商品説明       | 詳細説明文                     |
| 商品特徴       | セールスポイント               |
| 画像URL        | 商品画像のURL                  |
| 在庫数         | 現在の在庫数量                 |
| 販売ランク     | 人気ランク（小さいほど人気）    |
| タグ           | 検索用タグ（カンマ区切り）      |
| 季節タグ       | 適した季節                     |
| 用途           | 使用場所・用途                 |
| 廃番フラグ     | 0:販売中 / 1:廃番              |

## 注意事項

- AIは**商品マスターのデータのみ**を参照します（インターネット検索なし）
- 不明な場合は**「分かりません」と回答**するよう設計しています
- `.env` ファイルのAPIキーは**絶対に外部公開しない**でください
- 商品マスターの毎日自動更新は貴社のMySQLパイプラインで対応してください
